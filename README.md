## Pergunta central

> Qual ciclo econômico faz o mundo continuar vivo mesmo quando ninguém está em combate?

## Hipótese inicial

O jogo deve ser simples de entender, mas profundo de dominar. O motor principal não é o combate isolado, mas o ciclo entre coleta, produção, uso, desgaste, perda, reposição e desejo social.

## Regra de design

Toda mecânica precisa fortalecer pelo menos dois destes pilares:

- diversão imediata;
- economia viva;
- interação entre jogadores;
- histórias emergentes;
- resistência a bots, RMT e monopólios.
