# Mercado Negro e Loot

## Ideia-base

O jogo não deve criar equipamentos prontos do nada sempre que um monstro morre. O loot precisa estar conectado à produção dos jogadores.

## Modelo inspirado

```text
Jogador fabrica item
  ↓
Vende para mercado negro
  ↓
Sistema distribui para mobs e baús
  ↓
Outro jogador encontra como loot
```

## Valor do modelo

- mantém artesãos relevantes;
- reduz criação artificial de itens;
- conecta PvE e economia;
- cria demanda constante por equipamentos;
- transforma loot em redistribuição, não geração infinita.

## Versão simples para protótipo

1. Jogadores fabricam itens comuns.
2. Um NPC comprador aceita itens por preço dinâmico.
3. O sistema converte esse estoque em recompensas de PvE.
4. Itens quebrados ou perdidos aumentam demanda futura.

## Pergunta aberta
