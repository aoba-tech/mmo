# Template de Resumo

Use este modelo para resumir conversas importantes:

- **Contexto:** Descreva o contexto da conversa ou projeto.
- **Decisões:** Liste decisões tomadas.
- **Arquitetura:** (Opcional) Detalhe a arquitetura discutida.
- **Próximos passos:** Enumere próximos passos ou ações planejadas.
