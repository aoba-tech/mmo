# Squad Living Economy

Squad para evoluir a ideia do MMO com foco em simplicidade, diversão e economia viva.

## Objetivo

Discutir cada mecânica antes de virar implementação, validando impacto econômico, diversão, abuso potencial e simplicidade.

## Papéis

- [[Game-Economist]]
- [[Systems-Designer]]
- [[Behavioral-Psychologist]]
- [[MMO-Veteran]]
- [[Anti-Exploit-Designer]]
- [[Minimalist-Designer]]

## Rito de avaliação

Para cada ideia, responder:

1. Qual loop ela fortalece?
2. Que emoção ela gera?
3. Que abuso ela permite?
4. Como fica a versão mais simples?
5. Ela ajuda jogador casual e jogador hardcore?
6. Ela cria histórias emergentes?

## Critério de aprovação

Uma ideia só entra no backlog se for simples de explicar e fortalecer ao menos dois pilares do jogo.
