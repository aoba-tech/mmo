# Core Loop

## Loop essencial

```text
Coletar
  ↓
Refinar
  ↓
Fabricar
  ↓
Usar
  ↓
Desgastar / Perder / Quebrar
  ↓
Repor
  ↓
Coletar novamente
```

## Loop emocional

```text
Desejo
  ↓
Esforço
  ↓
Risco
  ↓
Conquista
  ↓
Apego
  ↓
Perda parcial ou total
  ↓
Novo desejo
```

## Regra

O loop deve ser jogável sem explicação longa. O jogador precisa sentir que sempre há uma ação útil e curta disponível.

## Atividades por sessão

### Sessão de 15 minutos

- coletar recursos próximos;
- fazer uma entrega curta;
- reparar ou preparar equipamento;
- participar de PvE leve.

### Sessão de 1 hora

- buscar recurso melhor;
- participar de dungeon;
- produzir lote simples;
- fazer comércio regional.

### Sessão longa

- escolta;
- disputa territorial;
- boss raro;
- operação de guilda;
- rota econômica arriscada.
